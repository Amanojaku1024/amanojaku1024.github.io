    程式專案 · 2026/11/16 · macOS

    youtube downloader

    從 Spotlight 開始，把下載、分類與重試留在原生視窗裡。

    下載 v1.0.0 原始碼包 ↓在 GitHub 檢視原始碼 ↗

    macOS 專用 · Python + AppKit · 安裝腳本與測試一併提供

    讓每天的操作簡單一點

    我想把原本需要打開 Terminal 的下載流程，改成隨時從 Spotlight 呼叫的小工具：貼上網址、選擇分類、確認後就交給背景程序處理。下載完成的 MP3 直接放進自己的分類資料夾，讓播放器也能沿用同一套整理方式。

    ⌘ Space搜尋捷徑youtube downloader
    02選網址與分類單曲或播放清單
    03確認後背景下載進度、結果與重試

    目前可以做什麼

    • 單曲與播放清單：支援 YouTube／YouTube Music。單曲模式即使網址帶有清單參數，也只處理指定影片。
    • 下載首數：每份清單都先選數量，一般清單可選全部；持續延伸的 Mix 則指定 1–500 首。
    • 按歌曲分配分類：選現有資料夾或新增分類，也能指定第 1–5 首放日文、第 8 首放古典。
    • 鋼琴標題規則：可依 Piano、鋼琴、ピアノ等字樣分到鋼琴。這是標題判斷，仍可能漏判或誤判；手動分配優先。
    • 原生進度視窗：顯示整體與當首進度、速度及預估剩餘時間；可搜尋、只看失敗、取消或重試。
    • 高品質 MP3：使用最佳可用音源轉碼，嵌入可取得的歌曲資訊與封面。

    分類資料夾就是音樂庫

    桌面／音樂／
├── 日文／歌曲.mp3
├── 英文／歌曲.mp3
├── 古典／歌曲.mp3
└── 鋼琴／歌曲.mp3

    不另外建立播放清單子資料夾。程式、資料庫、記錄與暫存則放在使用者的 Application Support。下載完成後，可用 Cog 等支援資料夾瀏覽的播放器直接聆聽。

    去重與中斷恢復

    不同分類與任務共用 SQLite Video ID 索引；同一影片已有有效音檔就直接跳過，並在結果列出原始位置。檔案被移除後可以重新取得。完全相同位元的音檔會再以 SHA-256 比對，不會因歌名相近就合併 Live、Cover 或 Remix。

    已提交的下載由 launchd 背景佇列執行，關閉捷徑或進度視窗不會取消。單曲失敗不阻止其他歌曲；重試沿用原清單快照，只處理尚未完成的內容。未知舊檔或不同編碼的同一歌曲，仍不能保證在下載前辨識。

    開始使用

    1. 準備環境：Homebrew、Python 3.10 以上，以及 Xcode Command Line Tools。下載包不捆綁這些工具。
    2. 下載並解壓縮：雙擊 install.command，檢查／安裝 yt-dlp、ffmpeg、Deno，並建立原生視窗與背景服務。安裝維護階段會開啟 Terminal。
    3. 建立捷徑：在 Apple 捷徑 App 新增 youtube downloader，加入「執行 Shell 工序指令」，貼上下方一行，再開啟「在 Spotlight 中顯示」。
    /bin/bash "$HOME/Library/Application Support/MusicDownloader/launcher.sh" ui

    日常使用只要按 ⌘ + Space 搜尋捷徑。首次執行需依系統提示授權指令稿、桌面檔案與通知。完整步驟及三分支原生選單寫法，見下載包中的 SHORTCUT_SETUP.md。

    更新下載引擎時，等任務完成後雙擊 update.command 即可。

    驗證與目前限制

    發布前在 Apple Silicon／macOS 26.6 重新執行 115 項隔離測試，涵蓋去重、刪檔恢復、同時啟動、部分失敗、中文路徑、分類、取消重試與進度解析。音訊整合測試使用自產短音源與真正的 yt-dlp／ffmpeg；不以單元測試宣稱所有線上歌曲都可下載。

    私人、已刪除或需要登入驗證的內容可能無法取得。全新帳號的安裝與授權、真實 iCloud Desktop 完整下載、不同 macOS 版本及 Spotlight 搜尋後執行的完整流程，仍需更多實機驗證。

    下載包包含原始碼、安裝腳本及測試，不含個人音樂、下載紀錄或本機捷徑簽章。這是可在自己的 Mac 安裝的工具，網頁提供介紹與下載。
