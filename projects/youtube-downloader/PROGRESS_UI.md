# 原生視窗與下載進度

日常入口維持 Spotlight 的「youtube downloader」。原生 AppKit 視窗提供較大的內容區域，可拖曳視窗邊緣調整大小。下載提交後，可以透過進度視窗查看目前任務；關閉視窗只關閉顯示，不會取消背景下載。需要停止下載時，請使用視窗中的取消操作。

## 安裝方式

原生視窗輔助程式的來源是 `native_ui.swift`，完整安裝會使用 macOS 的 Swift 編譯器建立：

```text
~/Library/Application Support/MusicDownloader/app/NativeUI.app/Contents/MacOS/MusicDownloaderUI
```

它使用 Apple AppKit，不需要額外 Python 套件。編譯需要 Xcode Command Line Tools；缺少時安裝程式會明確顯示錯誤，不會自動開啟工具安裝視窗。編譯快取位於 Application Support 的 `build-cache/`。

下載進行中也可由維護流程執行：

```sh
python3 install.py --ui-only
```

這個模式只部署 `frontend.py`、`progress_status.py`、安裝程式、Swift 來源與原生視窗程式，個別檔案以原子替換方式寫入。它不修改下載引擎、設定、資料庫或 LaunchAgent，也不重啟、取消或暫停既有下載。完整安裝仍會檢查進行中的任務，避免在下載時重新啟動服務。

## 顯示範圍

進度視窗從任務記錄及下載工具的記錄檔取得資訊。整個清單的完成數量與正在下載的單曲位元組進度代表不同階段；轉檔、封面處理、清單列舉或尚無可解析數值時，不能把顯示值當成整個任務的精確完成百分比。

## 視窗與控制

- 輸入與分類視窗預設內容約 780 × 540，進度視窗約 960 × 730；依可見螢幕範圍自動縮限，並可拖曳邊緣調整大小。
- 進度每秒更新；上方是已處理首數，包含下載、跳過與失敗。下方是當首真正的下載百分比、速度及當首下載剩餘時間。
- 讀取清單、準備、轉檔與封面處理若沒有可用百分比，顯示處理狀態及不確定進度動畫，不虛構完成百分比。
- 可切換任務、選歌曲查看原因／路徑，並使用取消任務、重試、完整結果及開啟音樂資料夾。
- 關閉視窗不取消任務；從捷徑「查看進度／重試／取消」可重新開啟。
